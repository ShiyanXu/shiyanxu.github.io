## 重复与冲突怎么处理

| 情况 | 处理 |
|---|---|
| 两份截图报告同一事实写两遍 | 只留一处，细节取更全者（分类报告带截图编号） |
| 「模型与 Harness 两层」在截图稿与长文里都讲 | 截图稿提供「不可内化」的论断，长文提供演进脉络与工程定义，合成一篇 [Harness 是什么](../04-Harness工程/01-Harness是什么.md) |
| 「上下文工程」在长文与提示词笔记里都出现 | 长文出机制（注意力预算、context rot、压缩 / 笔记 / 子代理），提示词笔记出操作技巧，交叉链接不重复 |
| 「长任务」有四套说法（Ralph Loop / Loop Engineering / 循环的五个动作 / 长时程 Harness） | 分别落在 01-Agent心法、07-工作流与循环、04-Harness工程，各自保留视角并互相链接 |
| 术语表错标 3 处（BPE 标成「检索增强」、MDP 标成「软体近端」、Token 释义偏移） | 已修正，见 [术语表](01-术语表.md) |
| 模型名 `GPT-6 Astro` 与文章标题 `Astra` 并存 | 保留原样，涉及处注明 |
| `03_Plugin/概念.md` 是 0 字节空文件 | 未纳入（没有内容可整理） |
| `文摘/文摘.md` 只有 14 个裸链接 | 归入 [零散书签](03-书签收藏.md)，不当作知识 |

## 被剔除的内容

| 类型 | 例子 | 处理 |
|---|---|---|
| 调侃 / 情绪评论 | 「卧槽，牛逼」「太强了」「学习」 | 剔除 |
| 表情包、颜文字 | 😅、「狗头」 | 剔除 |
| 平台热词标签 | 「大家都搜：AI 提示词」「知识星球」 | 剔除 |
| 点赞 / 转发 / 评论计数 | 「赞 21 评论 4 转发 9」 | 剔除（个别作热度参考） |
| 广告位 | 游戏推广卡片 | 剔除 |
| 无信息配图 | 相册缩略图墙、纯 UI 装饰 | 剔除 |
| 外链风险提示页 | 未备案域名警告页 | 剔除，仅留档 |
| 重复截图 | 同文重复 3 组 | 合并为一条 |
| 空文件 | `03_Plugin/概念.md` | 未纳入 |

**反向规则**：评论不是一律剔除。含作者补充、方法论、读者实践洞见或争议焦点的（如「评审 Agent 会被同化」「测试岗会进化」），一律摘录并标注来源。
