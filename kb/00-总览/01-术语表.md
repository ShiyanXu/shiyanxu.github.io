# 术语表

> 合并两份原报告的术语表并**修正了其中 3 处错标**（原表把 BPE 标为「检索增强」、把 MDP 标为「软体近端」、把 Token 标为「中文分词/词元」且释义偏移）。共 36 条，按主题分组。

## Agent 与编排

| 术语 | 英文 / 缩写 | 含义 |
|---|---|---|
| 智能体 | Agent | 能自主调用工具、多步推进并接受反馈直至任务完成的 AI 系统；与聊天机器人的关键区别是**以任务完成而非单轮回复为终点** |
| 智能体框架外壳 | Harness | 模型之外的工程外壳：系统提示词、工具定义与调用循环、上下文管理、权限沙箱、结果回灌、失败重试、检查点恢复；决定模型能力能否被真正释放 |
| 循环工程 | Loop Engineering | 让智能体定期检查状态、自主发现任务、执行更新并修复问题的范式；能力演进四阶段（提示 → 上下文 → Harness → 循环）的最后一环 |
| 拉尔夫循环 | Ralph Loop / Ralph Wiggum pattern | 不改提示、不喂历史，每轮从干净上下文用同一目标驱动 Agent，靠「产出 ↔ 目标」的差分收敛 |
| 计划模式 | Plan Mode | Agent 只输出方案、不动代码的模式，用于「先定方向、后写代码」 |
| 子代理 | Subagent | 拥有独立上下文与工具权限的任务执行体，由父代理委派，用于隔离上下文与并行 |
| 上下文蒸馏 | In-context Distillation | 推理时让小模型在大模型编排的工作流中执行，以低成本逼近大模型效果（区别于把知识蒸进权重的 KD） |

## 上下文与提示词

| 术语 | 英文 / 缩写 | 含义 |
|---|---|---|
| 上下文工程 | Context Engineering | 决定「回答这一刻上下文窗口里有什么」的工程实践：检索资料、工具结果、历史摘要、按需加载的 Skill |
| 上下文压缩 | Compaction / Compress | 历史超出窗口时的丢弃或摘要机制，天然带来信息损失，直接影响长任务连贯性 |
| 谄媚 | Sycophancy | 模型倾向附和用户以取悦人的行为（RLHF 副作用之一），可用系统提示词抑制 |
| 词元 | Token | 模型处理文本的最小单位；「Token 上下文」指可同时容纳的 token 数 |
| 子词切分 | BPE (Byte-Pair Encoding) | 把文本切成子词单元的算法，兼顾词表大小与未登录词 |

## Skills 与 MCP

| 术语 | 英文 / 缩写 | 含义 |
|---|---|---|
| 技能 | Skill | 打包指令、脚本与资源的目录（核心为 `SKILL.md`），按需加载以赋予 Agent 专门能力；2025-12-18 成为开放标准 |
| 渐进式披露 | Progressive Disclosure | Skill 的三层加载机制：元数据 → 指令 → 资源，只在需要时占用上下文 |
| 模型上下文协议 | MCP (Model Context Protocol) | 让 AI 应用标准化连接外部工具与数据源的开放协议；2025-12 捐赠给 Linux 基金会 |
| 计算机操作 | Computer Use | 模型直接「看屏幕、动鼠标键盘」的通用操作能力，适合无 API 的存量系统 |
| 调试桥 | adb (Android Debug Bridge) | 通过电脑向 Android 手机发送点击、输入、截屏、拉取文件等指令的官方工具 |

## 模型、推理与训练

| 术语 | 英文 / 缩写 | 含义 |
|---|---|---|
| 决策模型 | Decision Model | 输出「动作 / 选择」而非文本的模型；Jev 即此类，需与 LLM 配合 |
| 端侧模型 | On-device LLM | 运行在手机/PC 本地的模型，优势是隐私、低延迟、零 token 成本，瓶颈是内存与功耗 |
| 量化 | Quantization (Q4_K_M / FP8 / NVFP4) | 降低权重精度以省显存；数字越小越省显存、精度损失越大 |
| 键值缓存 | KV Cache | 推理时缓存历史 token 的 K/V 张量；**随上下文长度线性增长**，是长上下文本地部署的主要显存瓶颈 |
| 氛围编程 | Vibe Coding | 完全靠自然语言驱动、不细看代码的编程方式 |
| 近端策略优化 | PPO | 经典 RLHF 第三步使用的策略梯度算法 |
| 直接偏好优化 | DPO | 跳过奖励模型，用偏好对（chosen / rejected）直接优化策略 |
| 群体相对策略优化 | GRPO | 对同一 prompt 采样一组回答，用组内相对优势替代价值网络，省掉 Critic |
| 马尔可夫决策过程 | MDP | 顺序决策的数学框架，贝尔曼方程为其求解基础 |

## 底层原理

| 术语 | 英文 / 缩写 | 含义 |
|---|---|---|
| 因果遮罩 | Causal Mask | 自回归模型中遮蔽未来 token 的注意力掩码，保证「只能看前面」 |
| 缩放点积注意力 | Scaled Dot-Product Attention | `softmax(QKᵀ/√d_k)V`；Q 是「我在找什么」，K 是「我提供什么索引」，V 是「我实际携带的信息」 |
| 多头注意力 | Multi-Head Attention | 把 Q/K/V 投影到多个子空间并行计算再拼接，捕捉不同关系 |
| 快速注意力 | Flash Attention | 用分块与在线 softmax 减少 HBM 读写，数学等价下把显存降到 O(n) |
| 浏览器字节码 | WebAssembly (WASM) | 可在浏览器内高速运行的二进制指令格式，常用作 Rust/C++ 编译产物 |
| 网页编解码接口 | WebCodecs | 浏览器原生音视频编解码 API，使「浏览器内导出视频」成为可能 |
