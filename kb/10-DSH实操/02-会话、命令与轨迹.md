# 会话、命令与轨迹

> 输入框里藏着两个符号：`/` 和 ``。前者「加能力」，后者「点名东西」。另一个常被忽略的入口是「轨迹视图」——它决定你能不能查清 Agent 到底干了什么。

## 输入框的两个快捷键

| 符号 | 弹出 | 作用 |
|---|---|---|
| `/` | 命令与技能列表 | 让 Agent 带上某个技能/命令干活 |
| `@`（引用） | 技能、子代理、文件 | 把某个东西「点名」进这次对话 |

判断规则：**想加能力敲 `/`，想点名某个东西敲 `@`。** 引用可以夹在句子里，例如「用 @某某技能 把这份文档翻译成英文」。

斜杠命令的价值是**把复杂能力变成一句话**：技能怎么装、怎么跑由插件体系管，你只需要会选。

## 一个会话，两种视图

| 视图 | 内容 | 用途 |
|---|---|---|
| **对话** | 人话版：消息、回复、折叠的工具行 | 日常查看 |
| **轨迹** | 原始版：每一轮的完整记录 | 排查「它为什么这么干」 |

轨迹按轮次组织，每轮包含：

| 段 | 内容 |
|---|---|
| Turn | 第几轮、第几步 |
| USER | 你的原始输入 |
| CONTEXT | 注入的运行时上下文（权限、工作区、可用技能等） |
| ASSISTANT | 完整思考过程 |
| TOOL | 工具调用的原始 JSON 与返回 |

**什么时候切轨迹**：怀疑它漏看了上下文、想核对工具参数、想确认它真的读了文件而不是凭记忆回答。

## 会话行的三个操作

悬停会话行出现操作按钮：

| 操作 | 干什么 | 什么时候用 |
|---|---|---|
| 重命名 | 改一个更好认的名字 | 自动标题不满意 |
| **分叉** | 从某个节点复制出一条新线 | 想基于旧对话换个方向试 |
| 归档 | 收进归档，从列表隐藏 | 暂时不用的会话 |

**分叉不会动原会话**：原会话保留，新线独立演进。做实验、比方案时特别有用——这和「三个 Agent 各出一版 Plan」是同一种思路的轻量版。

## 一个实操建议

长会话里，**先分叉再冒险**：想试一个大改动，从当前节点分叉出去做；成了就合并思路，败了就丢掉那条线，主线不受污染。
