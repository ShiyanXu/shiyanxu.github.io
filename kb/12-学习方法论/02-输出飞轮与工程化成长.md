# 输出飞轮与工程化成长

> 三个来源讲的是同一件事：#67（践行费曼学习法）、#49（Loop Engineering 迁移到个人）、#27（为什么模型越强越要学习）。

## 一、学习与输出飞轮（#67）

宝玉xp 自述：「我一直是践行费曼学习法。」

具体形式：

```
写作 → 为了写作去学习与实践 → 分享 → 接收反馈 → 再写作
（输出 → 实践 → 分享 → 反馈 → 再输出）
```

关键在**「为了写作去学习」**：写作不是学习的产物，而是学习的触发器。没有输出目标，输入会退化成「收藏即学会」。

## 二、把个人成长做成一套 Loop Engineering（#49）

AI 协作场景下，这个闭环可以外挂 AI 来加速：

```
定义想做 → AI 帮你做成 → 你验收 → 分享出去收反馈
        → 把经验写出来 → AI 帮你整素材 → 输出倒逼你系统思考
```

「小循环做项目，大循环做分享。循环建立起来、越转越快，成长就越快。」

## 三、两个理论支撑

**飞轮效应**（吉姆·柯林斯《从优秀到卓越》）：各环节相互强化，转动越来越省力、越来越快。输出带来反馈，反馈带来新的输入，形成复利式成长。

**双环学习**（Chris Argyris）：

| | 单环 | 双环 |
|---|---|---|
| 改什么 | 在既有目标下改进做法 | 质疑目标与假设本身 |
| 对应 | 验收 → 改进 | 输出倒逼系统思考 |

「验收 → 改进」是单环，「输出倒逼系统思考」是双环。两者合起来，才配得上「工程化成长」。

## 四、为什么模型越强，学习越重要（#27）

Skill 的价值在于把「品味与判断力」固化；而品味与判断力来自持续的阅读与思考积累。

阅读的价值不在于字数（一本书可能不足 1M token），而在于阅读过程中每一段的思考与累积。因此**通过学习和阅读提升品味与判断力，仍然有价值**——这是模型再强也替代不了的部分。

## 五、落地：一张周表

| 时间 | 动作 | 产出 |
|---|---|---|
| 周一 | 选一个主题，列出「我已经知道的」 | 问题清单 |
| 周二–周三 | 边学边写 800 字解释 | 初稿 |
| 周四 | 标出讲不清的地方，回补资料 | 修订稿 |
| 周五 | 发布，收集反馈 | 反馈清单 |
| 周末 | 把反馈变成下一轮的问题 | 下一周主题 |

## 六、常见断点

1. **只输入不输出**：收藏夹越来越厚，能力不动。
2. **只输出不复盘**：写了一年，同一个坑反复踩。
3. **只在小圈子里发**：反馈同质化，得不到真问题。
4. **把 AI 当读者**：AI 的反馈偏「鼓励型」，要主动要求它挑错。
