# 预训练、微调与 RLHF（PPO / DPO / GRPO）

> 素材来源：《Hands on Modern RL》（#10）与深度学习笔记（#6）。这一节解释「模型为什么会对话、又为什么需要对齐」。

## 训练的三个阶段

| 阶段 | 做什么 | 产物 |
|---|---|---|
| 预训练 | 在海量无标注语料上预测下一个词 | 基座模型（会续写，不一定会对话） |
| 监督微调（SFT） | 用「指令-回答」样本教它按格式回答 | 指令模型 |
| 对齐（RLHF 家族） | 用人类偏好让回答更有用、更安全 | 对话模型 |

## RLHF 家族：PPO / DPO / GRPO

| 方法 | 核心思路 | 工程代价 |
|---|---|---|
| **PPO** | 用奖励模型打分，再用策略梯度更新 | 需同时维护策略 / 参考 / 奖励 / 价值四个模型，最重 |
| **DPO** | 跳过奖励模型，直接用偏好对（chosen / rejected）优化策略 | 转化为监督学习目标，简单稳定 |
| **GRPO** | 对同一 prompt 采样一组回答，用**组内相对优势**代替价值网络 | 省掉 Critic，显存与工程成本最低，适合大规模推理类 RL |

直觉理解：
- PPO 像「请一个裁判打分，再按分数练习」；
- DPO 像「直接看「这个回答比那个好」的对比数据来练」；
- GRPO 像「同一道题做十遍，和自己比，比平均好就加分」。

## 数学骨架：MDP 与贝尔曼方程

```
V(s) = max_a [ R(s,a) + γ · Σ P(s' | s,a) · V(s') ]
```

MDP 把「顺序决策」形式化为状态、动作、奖励、转移；贝尔曼方程给出「当前状态的价值 = 最优动作的即时奖励 + 折扣后的未来价值」。这是所有 RL 算法的共同起点。

## 《Hands on Modern RL》的章节逻辑

1. **零基础跑通第一个 RL 脚本**：CartPole 倒立摆，获得「AI 能自己学会一件事」的第一手感受；
2. **从游戏控制切到语言对齐**：用完整的 DPO 微调流程让大模型学会「不盲从用户」；
3. **数学基石 MDP**：从多臂老虎机出发，建立形式化框架，推导贝尔曼方程；
4. **深度强化学习**：DQN 把 Q-Learning 从表格搬进神经网络，用经验回放与目标网络从 Atari 像素学决策；
5. **策略梯度**：从 REINFORCE 到带基线的策略梯度；
6. **Actor-Critic**：引入优势函数与 Critic，让 Value-Based 与 Policy-Based 两条路线汇合。

这本书的定位：主流教材对 RL「一笔带过」，专门的 RL 教材又停留在传统框架，对 PPO、DPO、GRPO 只字不提——它填补的是「经典教材」与「最新论文」之间的鸿沟。

## 与「谄媚」的关系

RLHF 用人类偏好打分，副作用是模型学会「附和用户以获取更高评分」。这解释了为什么需要反谄媚的系统提示词（见 [安德森提示词与反谄媚](../03-提示词工程/04-安德森提示词与反谄媚.md)）——**对齐目标本身会塑造模型的性格**。
