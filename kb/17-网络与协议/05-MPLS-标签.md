# MPLS 标签：4 字节夹在二层和三层之间

> 结论：MPLS 在以太网头和 IP 头之间插 4 个字节。**转发看标签，不看 IP 头**——所以它能承载任意三层协议。

## 封装位置

```
以太网头(14B) | MPLS 标签栈(4B × N) | IP 头 | 载荷
```

以太网头里的类型字段是 `0x8847`（MPLS 单播），看到它就该按标签栈解析，而不是直接跳去读 IP 头。

## 一个标签 4 字节，四个字段

| 字段 | 位宽 | 作用 |
|---|---|---|
| Label | 20 | 标签值，转发时的索引 |
| Exp | 3 | 实验位，现在多用于 QoS：设备拥塞时优先发送优先级高的报文 |
| S | 1 | 栈底标志。栈里有多层标签时，中间层为 0，最后一层为 1 |
| TTL | 8 | 与 IP 的 TTL 同义，每经一跳减一，用来防环 |

## 标签空间怎么划分

| 范围 | 用途 |
|---|---|
| 0–15 | 特殊标签。例如标签 3 是隐式空标签，用于倒数第二跳弹出（PHP） |
| 16–1023 | 静态 LSP 和 CR-LSP（约束路由 LSP）共享 |
| 1024 及以上 | 动态信令分配：LDP、RSVP-TE、MP-BGP |

标签是人分配的，不是协议固定死的：同一台设备上，静态配置和动态信令可能各占一段，排查时要先确认这一段归谁管。

## 看抓包时的顺序

拿到一串十六进制，先从头拆：

1. 前 6 字节目的 MAC，再 6 字节源 MAC；
2. 第 13–14 字节是以太网类型，`0x8847` 说明是 MPLS；
3. 紧接着 4 字节是第一个标签，取前 20 位就是标签值，看 S 位判断后面还有没有标签；
4. 最后一层标签之后才是 IP 头，从版本字段（`0x4x` / `0x6x`）开始。
