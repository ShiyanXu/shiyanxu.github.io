# IPv4 报头：20 字节固定头，剩下全在选项里

> 结论：IPv4 头是**固定 20 字节 + 最多 40 字节选项**。分片、校验和、TTL 都放在头里，所以每过一个路由器，它都要被算一遍。

## 布局（每行 4 字节）

| 字节 | 内容 |
|---|---|
| 0 | 版本(4 位) + 首部长度(4 位) |
| 1 | 服务类型 TOS(8 位) |
| 2–3 | 总长度(16 位) |
| 4–5 | 标识(16 位) |
| 6–7 | 标志(3 位) + 片偏移(13 位) |
| 8 | 生存时间 TTL(8 位) |
| 9 | 协议(8 位) |
| 10–11 | 首部校验和(16 位) |
| 12–15 | 源 IP |
| 16–19 | 目的 IP |
| 20+ | 选项 + 数据 |

## 逐字段

| 字段 | 位宽 | 要点 |
|---|---|---|
| 版本 | 4 | 4 = IPv4，6 = IPv6 |
| 首部长度 | 4 | 单位是 4 字节，最大 15 → 60 字节；扣掉 20 字节固定部分，选项最多 40 字节 |
| TOS | 8 | 3 位优先级 + D/T/R + 1 位保留；D=延迟最小，T=吞吐最大，R=可靠性最高 |
| 总长度 | 16 | 头 + 数据，最大 65535；有效载荷 = 总长度 − 首部长度 |
| 标识 | 16 | 每发一个报文加一；分片后所有分片沿用同一个标识，用来重组 |
| 标志 | 3 | 实际只用到两位：DF=1 不分片，MF=1 表示「后面还有片」 |
| 片偏移 | 13 | 本片在原报文中的位置，单位 8 字节，所以计算要乘 8 |
| TTL | 8 | 每过一个路由器减一，为 0 丢弃；初始值常见 64、128、255 |
| 协议 | 8 | 上层协议，见下表 |
| 校验和 | 16 | 只算首部，不含数据 |
| 选项 | 可变 | 见下节，需补齐到 4 字节边界 |

## 常见协议号

| 号 | 协议 |
|---|---|
| 1 | ICMP |
| 2 | IGMP |
| 6 | TCP |
| 17 | UDP |
| 47 | GRE（用于 ERSPAN） |
| 88 | IGRP |
| 89 | OSPF |

## 首部校验和怎么算

发送端：

1. 校验和字段先置 0；
2. 把首部按 16 位累加（反码运算，进位回卷加回低位）；
3. 结果取反，填入校验和字段。

接收端：

1. 把含校验和在内的所有 16 位字再累加一次；
2. 结果为 0 说明没传错，否则丢弃。

注意「反码求和」不是简单相加：`0xFFFF + 0x0001` 要回卷成 `0x0001`，不是 `1 0000`。

## 选项：40 字节里能放什么

选项码 1 字节 + 长度 1 字节 + 数据；选项码里还分 1 位「复制」、2 位「选项类」、5 位「选项号」。复制位为 1 表示分片时复制到每一片，为 0 则只留在第一片。

常见的几个：

| 选项号 | 功能 |
|---|---|
| 0 | 选项结束 |
| 1 | 无操作（用于对齐） |
| 2 | 安全与处理限制 |
| 7 | 记录路由（Record Route） |
| 9 | 严格源路由（下一跳必须直连） |
| — | 宽松源路由（允许中间跳过若干路由器） |
| — | 时间戳（记录经过路由器的时间） |

因为首部长度以 4 字节为单位，选项不足 4 字节整数倍时要填充 0。
