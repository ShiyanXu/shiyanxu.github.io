# M1 通识与直觉

> 一句话：这一模块不为动手，只为**建立画面**——AI 与 ML 的边界在哪、模型到底在优化什么、一个神经元到一层网络差在哪、大模型的全套黑话各指什么。学完能听懂别人在说什么，不会把「训练」和「调用」混为一谈。

---

## M1-01 AI 的三个圈

**一句话**：AI 是目标，机器学习是达成目标的方法，深度学习是机器学习里目前最有效的那一类方法。

### 是什么

三层同心圆，从外到内依次收窄：

| 层 | 定义 | 典型做法 |
|---|---|---|
| 人工智能 AI | 让机器完成需要智能的任务 | 规则系统、搜索、机器学习都可以 |
| 机器学习 ML | 不写规则，从数据里拟合规律 | 线性回归、决策树、SVM、神经网络 |
| 深度学习 DL | 用多层神经网络做机器学习 | CNN、Transformer、扩散模型 |

关键区别在**规则由谁写**：AI 的早期做法是人写 if-else（专家系统），ML 是把「输入→输出」的样例交给算法，让它自己找规则。

### 怎么运作

一个机器学习系统的三段：

```
数据 → 模型（带可调参数） → 预测 → 与答案比较得到损失 → 调整参数 → 回到预测
```

「学习」= 反复调整参数，让损失变小。深度学习只是把「模型」换成了一个有很多层的函数，参数从几十个变成几十亿个。

### 什么时候用它

判断一个需求该不该上 ML，看两件事：**规则能不能写清**、**有没有样例**。

- 规则能写清且稳定（税率计算、日期换算）→ 直接写代码，别上模型。
- 规则写不清但样例很多（识别猫、判断语气）→ 上 ML。
- 规则写不清、样例也没有 → 先把数据搞出来，否则模型无从学起。

### 易错点

1. **把 AI 等同于大模型**。大模型只是深度学习里的一支；推荐系统、语音识别大多是别的架构。
2. **以为深度学习「更聪明」**。它更强的地方是**免手工特征**，不是逻辑推理；小数据上反而常输给简单模型。
3. **把「调用 API」说成「训练模型」**。调 API 时参数一个都没变，你的工作全在提示词和工程侧。

## M1-02 机器怎么学

**一句话**：学习 = 在一个高维山坡上摸黑下山，损失是高度，梯度是脚下的坡度，学习率是每步迈多大。

### 是什么

四个必须同时理解的概念：

| 概念 | 含义 | 出错的表现 |
|---|---|---|
| 损失 loss | 预测与答案的差距，一个标量 | 损失不降 → 模型没学到 |
| 梯度 gradient | 损失对每个参数的偏导，指向「上升最快」的方向 | 梯度爆炸/消失 |
| 学习率 lr | 沿反方向走一步的幅度 | 太大震荡发散，太小慢到放弃 |
| 过拟合 | 训练集很好、新数据很差 | 训练损失降、验证损失升 |

### 怎么运作

```
初始化参数（随机）
重复：
  前向：算预测，算损失
  反向：算每个参数的梯度（链式法则）
  更新：参数 ← 参数 − 学习率 × 梯度
直到验证损失不再下降
```

三个配套动作缺一不可：**划数据**（训练/验证/测试三段，测试集只在最后碰一次）、**看曲线**（训练与验证两条损失一起看）、**调超参**（学习率、批大小、层数——这些不是学出来的，是人定的）。

梯度下降有三种常见变体：全量（慢但稳）、随机 SGD（快但抖）、小批量 mini-batch（工业默认）。

### 什么时候用它

这套流程适用于一切「有答案的」任务（监督学习）。判断能不能用，只问一句：**我有没有足够多的「输入-正确答案」对？**没有答案就得换范式（自监督、强化学习），而不是硬套。

### 易错点

1. **只看训练损失**。训练损失一路降到 0 往往是灾难信号，不是好消息。
2. **把「过拟合」当成「模型太强」**。多数时候是数据太少或太单一，加正则只是止血。
3. **拿测试集调参**。调一次就污染一次，最后报的指标全是自欺。

## M1-03 一个神经元

**一句话**：神经元 = 加权求和 + 一个非线性开关；一层神经元 = 同时问很多个问题；多层 = 把答案再当输入问下去。

### 是什么

单个神经元的计算只有三步：

```
z = w1x1 + w2x2 + ... + wnxn + b     # 加权求和，w 是权重，b 是偏置
a = 激活函数(z)                      # 常见 ReLU：max(0, z)
输出 a
```

- **权重 w**：这个输入有多重要。
- **偏置 b**：整体门槛，可以理解为「不输入任何东西时的默认倾向」。
- **激活函数**：制造非线性。没有它，叠一百层也等价于一层线性变换。

### 怎么运作

一层 = 一批神经元并行，每个有自己的 w 和 b，输出拼成向量。多层 = 上一层的输出向量作为下一层的输入。

```
输入 x (n 维)
  → 隐层1：m 个神经元 → 得到 m 维向量
  → 隐层2：k 个神经元 → 得到 k 维向量
  → 输出层：1 个神经元 → 一个分数
```

为什么必须非线性：线性函数的复合还是线性函数，`f(g(x))` 仍是一条直线；只有夹进 ReLU / sigmoid / tanh，网络才能拟合弯曲的边界。

### 什么时候用它

MLP（多层感知机）是通用逼近器，理论上能拟合任何连续函数，但**不编码任何结构先验**——它不知道相邻像素有关、也不知道词的顺序。所以图像要用 CNN（局部+共享），序列要用 RNN/Transformer（顺序+注意力）。选架构的本质是**把领域知识写进结构**，而不是靠数据硬学。

### 易错点

1. **以为激活函数是为了「更像大脑」**。它是为了解决线性不可分，和生物无关。
2. **加层就一定更强**。层数上去后梯度会不稳定，需要残差、归一化配合，否则越深越差。
3. **把权重当成「重要性打分」直接解释**。多层的权重不能单独解读，这是可解释性的难点所在。

## M1-04 LLM 全景与术语

**一句话**：大语言模型是一个「给一段文本、预测下一个 token」的函数；围绕它的所有工程，都是在**决定喂它什么、让它能碰到什么、怎么判断它做对了**。

### 是什么

先把黑话一次对齐：

| 术语 | 是什么 | 一句话判据 |
|---|---|---|
| token | 模型处理的最小单位，介于字与词之间 | 计费和长度都按它算，不按字数 |
| 上下文窗口 | 一次请求里模型能同时看到的 token 上限 | 超了就得裁、就得压 |
| prompt | 你给的输入，含系统提示与用户消息 | 它不是「命令」，是条件 |
| embedding | 把文本压成一串数字（向量） | 语义相近 → 向量距离近 |
| RAG | 先检索再让模型基于检索结果回答 | 解决「不知道」和「记不住」 |
| function calling | 模型输出「我要调哪个函数、参数是什么」 | 模型不执行，只提议 |
| agent | 能自己决定下一步、并调用工具的系统 | 关键在「循环 + 决策」 |
| MCP | 一套让外部工具按统一协议接入的标准 | 解决工具接入的重复劳动 |
| 参数规模 | 模型里可调数字的个数（7B = 70 亿） | 不等于能力，只是成本的一维 |

### 怎么运作

一次调用的完整链路（务必能背下来）：

```
你的文本
 → 分词器切成 token 序列
 → 加进上下文（system + 历史 + 本次输入）
 → 模型逐 token 预测下一个，直到遇到停止条件
 → 输出 token 序列 → 反分词成文本
```

由此推出三个必然结论：
1. **模型没有记忆**。所谓「记得」，是每次都把历史重新塞进上下文。
2. **模型不查资料**。它只根据上下文里的内容做概率推断，所以要有 RAG 或工具。
3. **同一输入可能不同输出**。采样带随机性，temperature 控制这个随机程度。

### 什么时候用它

LLM 擅长：改写、总结、分类、抽取、生成草稿、按格式输出、在给定材料内问答。
LLM 不擅长：精确算术、最新事实、长链严格推理、需要真实副作用的操作。
**判据**：如果一个任务「答案在给定材料里，或只需语言变形」→ 直接上；如果「答案在外部世界或需要执行」→ 必须配检索或工具。

### 易错点

1. **把上下文当数据库**。塞进去的东西越多，模型越容易忽略中间部分（lost in the middle），且成本线性上涨。
2. **以为模型会「记住上次说过的话」**。不塞历史就是全新的会话。
3. **把「流畅」当「正确」**。语言模型的训练目标是像人话，不是说实话，这是幻觉的根源。
