# 机器学习基础（前置知识）

> 这一章不是「机器学习入门课」，而是**读得懂公式的那层底座**：符号、线性代数、微积分、概率统计、最优化、NumPy 六块，只讲在 ML 的模型、推导和实现里反复出现的那部分。它排在 Agent 相关内容之前，因为后面 [Transformer 与注意力机制](../09-LLM原理与训练/01-Transformer与注意力.md) 里的每个式子，都默认你会这些。

## 课程档案

原始材料是一份英文课程大纲 *Machine Learning Prerequisites — Course Syllabus*，两页，自编讲义。

## 课程定位

它的取舍是**选择性**而非百科式：每个主题之所以入选，是因为它在 ML 的模型、推导或实现里反复出现。要练的是四件事——数学记号、线性代数、微积分、概率统计与最优化，外加用 NumPy 做数值计算。

中心目标只有一句：**在进入主课程之前，能在「数学表达式 / 几何解释 / 计算表示」三种语言之间自由来回。** 这个目标和本库的整体风格是一致的——符号不认识，后面所有原理笔记都只能看个热闹。

## 学完能做到什么

- 读懂机器学习里常见的数学记号；
- 用向量和矩阵表示数据与变换；
- 直观且能在计算层面讲清内积、投影、秩、特征值、SVD 与 PCA；
- 算导数和偏导，处理 Jacobian 与 Hessian；
- 对多变量与矩阵形式的表达式熟练套用链式法则；
- 理解随机变量、概率分布、期望、方差、条件概率与贝叶斯定理；
- 说清 MLE 与 MAP 的区别；
- 理解梯度下降、学习率、凸性、正则化与约束在训练中扮演的角色；
- 用 NumPy 的数组、broadcasting、矩阵运算和向量化实现这些数学表达式。

第 8 条是这门课真正的落点：**凸性、学习率、正则化不是术语，是调参时的三个旋钮。**

## 推荐学习顺序

两条链，是同一门课的外延与内延：

```
前置链：数学记号 → 线性代数 → 微积分与矩阵微积分 → 概率与统计 → 最优化 → Python / NumPy
```

```
接主课程：线性回归 → 逻辑回归 → 损失函数 → 优化 → 正则化
        → 神经网络 → 表示学习 → 嵌入 → 注意力与 Transformer
```

前一条链到这里结束，后一条链的终点正是本库 09 目录开头那篇 Transformer 的位置。也就是说：**这一章是 09 的上游，中间隔着一整门机器学习课。**

## 教学法四条

大纲里明确写了四条取舍，可以直接当成读这一章的方法：

1. **先直觉，后记忆**——先弄懂表达式在说什么，再去背解法步骤；
2. **先有用，后完整**——只讲「理解 ML 直接需要」的部分，不追求数学上的完备；
3. **能几何就几何**——向量、投影、梯度、特征向量、降维，尽量给出可视化的几何图像；
4. **数学与代码对齐**——每个数学记号都配一个 NumPy 表示，方便后面把公式直接翻成代码。

## 前置期望

- 不要求任何机器学习经验；
- 建议有高中数学代数基础；
- 会一点 Python 有帮助，但不是必需；
- 鼓励在学习过程中**复现关键推导与数值例子**——这一条和本库 [费曼学习法](../12-学习方法论/01-费曼学习法.md) 是同一个意思。
