# 数学符号与读法（Module 01）

> 这张表解决的不是「理解」，而是「读」：看到一个英文术语、一个希腊字母、一个公式，能当场念出来、知道它在模型里指什么。核心不是记住所有符号，而是熟悉那条链——**输入 → 模型 → 预测 → 损失 → 优化**。

这是课程 Module 01「Mathematical Notation and Reading」的落地版：符号表、读音、公式读法都在这里，后面五个模块（线性代数、微积分、概率、优化、NumPy）默认你已经过了一遍这张表。整门课的模块地图见 [导读](00-导读.md)。

## 二、希腊字母与常见含义

| 符号 | 英文读法 | 机器学习中的常见含义 |
|---|---|---|
| x | x | 输入、特征（feature） |
| y | y | 标签、目标变量（target） |
| X | capital X | 数据矩阵 |
| w | double-u | 权重（weight） |
| b | bee | 偏置（bias） |
| θ | theta | 模型参数 |
| α | alpha | 学习率、系数等 |
| β | beta | 回归系数、参数 |
| γ | gamma | 折扣因子等 |
| λ | lambda | 正则化系数 |
| μ | mu | 均值（mean） |
| σ | sigma | 标准差，或函数符号（见下一节） |
| σ² | sigma squared | 方差（variance） |
| ε | epsilon | 小误差、探索概率等 |
| δ | delta | 变化量、阈值 |
| η | eta | 常用于表示学习率 |
| ρ | rho | 相关系数等 |
| τ | tau | 温度参数、阈值 |
| φ | phi | 特征映射（feature map） |
| ψ | psi | 函数、状态表示等 |
| ω | omega | 权重、频率等 |

约定俗成的大小写分工：**小写粗体是向量、大写是矩阵**（`X` 是数据矩阵、`x` 是单条样本），小写希腊字母多指标量超参，`θ` 几乎专指「要学的那堆参数」。

## 三、Sigma 与 Sigmoid 不是同一个词

初学最容易混的一处：

- **σ** 是希腊字母，读 **sigma**（`ˈsɪɡmə`）；
- **sigmoid** 是函数名，读 **sigmoid**（`ˈsɪɡmɔɪd`），不是 "sigma" 加个 d。

麻烦在于逻辑回归里把 sigmoid 函数记作 σ，于是**同一个 σ 既是字母、又是函数符号**：

```
σ(z) = 1 / (1 + e^(−z))
```

读的时候要分两层：

| 读什么 | 怎么念 |
|---|---|
| 符号 σ | sigma |
| 函数本身 | Sigmoid Function |
| 整个公式 | "Sigma of z equals one over one plus e to the minus z." |

`e` 读 "e"（欧拉数），`e^(−z)` 读 "e to the minus z"。

## 四、表达式怎么念

| 数学表达式 | 英文读法 |
|---|---|
| xᵢ | x sub i |
| xᵢⱼ | x sub i j |
| x² | x squared |
| x³ | x cubed |
| xᵀ | x transpose |
| wᵀx | w transpose x |
| ŷ | y hat |
| x̄ | x bar |
| ‖x‖ | norm of x |
| \|x\| | absolute value of x |
| Σ | sum / summation |
| Π | product |
| ∇ | nabla / gradient |
| ∂ | partial |
| ∂L/∂w | partial L with respect to w |
| argmin | arg min |
| argmax | arg max |
| E[X] | expectation of X |
| P(y \| x) | probability of y given x |
| p(x) | p of x |
| f(x) | f of x |

三条通用规则，比逐条背更省力：

1. **上下标**：下标读 `sub`，平方读 `squared`，立方读 `cubed`，转置读 `transpose`；
2. **头上的小帽子 / 横线**：`hat` 是预测值（ŷ = 模型猜的 y），`bar` 是均值（x̄）；
3. **算子**：`Σ` / `Π` 是求和 / 连乘，`∇` 是梯度（nabla），`∂` 是偏导（partial），带 `arg` 的是「求使后面式子最大/最小的那个自变量」。

## 五、七个核心公式

### 1. 线性回归 Linear Regression

```
ŷ = wᵀx + b
```

`w = weight`，`b = bias`。读作："Y hat equals w transpose x plus b."

### 2. 均方误差 Mean Squared Error

```
MSE = (1/n) Σᵢ (yᵢ − ŷᵢ)²
```

可直接读字母 **M-S-E**，或念全称 **Mean Squared Error**。

### 3. Sigmoid 函数

```
σ(z) = 1 / (1 + e^(−z))
```

逻辑回归里最常见的激活函数。照第三节的分层读：σ 读 sigma，函数名读 sigmoid。

### 4. Softmax

```
P(y = k | x) = e^(z_k) / Σⱼ e^(zⱼ)
```

读 **soft-max**，把一组实数压成和为 1 的概率分布，用于多分类。

### 5. ReLU

```
ReLU(x) = max(0, x)
```

读 **ree-loo**，全称 **Rectified Linear Unit**（修正线性单元）。

### 6. 交叉熵损失 Cross-Entropy Loss

```
L = − Σₖ yₖ log pₖ
```

英文直接念 **Cross-Entropy Loss**，分类问题里几乎处处都在用它。

### 7. 梯度下降 Gradient Descent

```
θₜ₊₁ = θₜ − η ∇θ L(θₜ)
```

`θ` = 模型参数，`η` = learning rate，`∇θ L` = loss 关于参数 θ 的梯度。整句读作：

> "Theta at t plus one equals theta at t minus eta times the gradient of L with respect to theta."

## 六、先记这十个

`θ, λ, σ, μ, ε, η, ∇, ∂, ŷ, arg min`

| 符号 | 读法 |
|---|---|
| θ | theta |
| λ | lambda |
| σ | sigma |
| μ | mu |
| ε | epsilon |
| η | eta |
| ∇ | nabla / gradient |
| ∂ | partial |
| ŷ | y hat |
| arg min | arg min |

这十个覆盖了绝大多数损失函数、优化器和正则项的写法：**θ 是要学的东西，η 是步子大小，λ 是惩罚力度，∇ 和 ∂ 是求导的两种写法，ŷ 是模型输出，σ 既当字母也当 sigmoid，arg min 是「求最优解」的口头禅。**
